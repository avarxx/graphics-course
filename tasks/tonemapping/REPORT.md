# Тон-маппинг и цветокоррекция

## Что сделано

- Сцена рендерится в HDR `B10G11R11_UFLOAT`, в бэкбуфер переносится шейдером постобработки.
- Compute-шейдеры считают min/max `log2` яркости и гистограмму из 100 корзин.
- Экспозиция выбирается по гистограмме: усечённое среднее (можно медиану/среднее), с
  временной адаптацией в лог-пространстве, чтобы не было скачков при движении камеры.
- Кривые: Clamp, Reinhard, ACES, Hable. По умолчанию ACES.
- sRGB-кодирование, дизеринг, отдельные переключатели тон-маппинга и цветокоррекции в ImGui.
- 3D LUT 32×32×32 `R8G8B8A8_UNORM`: строится из пар source/graded, пустые ячейки заполняются
  ближайшими, применяется с трилинейной фильтрацией и регулируемой силой.
- min/max и гистограмма есть в двух вариантах: shared memory и глобальные атомики.

## Запуск

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target tonemapping -j8
./build/tasks/tonemapping/tonemapping
```

Флаги:

```
--no-tonemap | --no-grading | --lut NAME | --tonemap-op N
--no-srgb | --no-dither | --global-atomics | --screenshot out.png
--debug-view N | --camera fx fy fz tx ty tz | --no-gui | --print-timings
```

## Замеры

Apple M3, 2560×1440, 80 кадров:

| Проход | shared, мс | global, мс |
|---|---|---|
| Lum min/max | 0.47 | 0.38 |
| Histogram | 0.44 | 3.78 |
| Exposure | 0.05 | 0.01 |

Гистограмма с глобальными атомиками медленнее в 8–9 раз: соседние пиксели часто попадают в одну
корзину и бьют в один адрес. На min/max разница в пределах шума.

## Ограничения

- Экспозиция адаптируется по всему кадру, локального тон-маппинга нет.
- LUT фиксированного размера 32³; строится на CPU при старте.
